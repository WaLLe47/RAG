# Папка для данных RAG

📁 **Назначение:** сюда кладите документы, по которым будет работать RAG.

## Поддерживаемые форматы

- `.pdf` — PDF-документы
- `.docx` — документы Word
- `.txt` — текстовые файлы

## Как использовать

**Через CLI:**

```bash
python app/main.py --doc data/your_file.docx --query "О чём документ?"
```

**Через веб-интерфейс:**

```bash
uvicorn app.server:app --reload --port 8000
```

Затем откройте http://localhost:8000 и загрузите файл через интерфейс.
